1. Create an AgentInstrumentation resource to enable injection:

   kubectl apply -f - <<EOF
   apiVersion: aep.dev/v1alpha1
   kind: AgentInstrumentation
   metadata:
     name: default
   spec:
     enabled: true
     aepServerURL: {{ .Values.aepServerURL }}
   EOF

2. Annotate pods to opt in to sidecar injection:

   kubectl annotate pod <pod-name> aep.dev/inject=true

   Or add to your Deployment pod template:
     annotations:
       aep.dev/inject: "true"

3. Monitor injection status:

   kubectl get ainstr

4. View operator logs:

   kubectl logs -n {{ include "aep-operator.namespace" . }} \
     deployment/{{ include "aep-operator.fullname" . }}
